# 가맹점 런처 (`apps/launcher`)

매장 태블릿에 전체 화면으로 띄우는 손님용 키오스크입니다. 백오피스의 조회 API(`/api/kiosk/...`)를 읽어 이 매장의 게임과 지금 빌릴 수 있는지를 보여줍니다.

| 화면 | 경로 | 내용 |
|---|---|---|
| 시작 | `/` | 매장 이름, 보유·이용 가능 게임 수, 메뉴(게임 둘러보기·예약 확인·대기 등록) |
| 예약 확인 | `/reservation` | 큰 숫자 패드로 전화번호 뒷자리 4자리를 누르면 오늘 예약(이름은 가림)이 나오고, '도착했어요'로 직원에게 도착을 알림 |
| 현장 대기 | `/waitlist` | 지금 대기 팀 수, 대기 등록(인원·이름·휴대전화 → 대기 번호와 앞 팀 수), 뒷자리로 내 순서 확인(호출되면 안내) |
| 게임 둘러보기 | `/games` | 인원·유형·"지금 이용 가능한 게임만"으로 거르기. 이용 가능한 게임을 먼저 보여줌. 90초 동안 만지지 않으면 시작 화면으로 돌아감 |

- 백오피스에 연결할 수 없거나 매장이 없으면(폐점 포함) 손님에게 안내 문구를 보여줍니다.
- 설정은 환경 변수 `BACKOFFICE_URL`, `LAUNCHER_CAFE_ID`, `KIOSK_API_TOKEN`(백오피스와 같은 값, 선택)입니다(`.env.example`).
- 백오피스 주소·토큰은 서버에만 두고, 화면은 서버 액션(`src/app/actions.ts`)을 거쳐 백오피스 API를 부릅니다.
- 손님 화면이라 전화번호는 보여주지 않고, 이름은 가려서(김*수) 보여줍니다.
- 화면은 손으로 누르기 쉽게 큰 버튼을 쓰고, 확대·글자 선택을 막아 둡니다.

```bash
pnpm dev:launcher   # 루트에서. 백오피스(3000)와 런처(3001)를 함께 띄움
```

응답 형태는 `@avocado/domain/kiosk`, 응답을 만드는 쪽은 `apps/admin/src/app/api/kiosk`입니다.
