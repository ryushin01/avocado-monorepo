# 실기기 QA 체크리스트 (v1.0.0 태그 전)

자동 검사(단위 테스트, E2E, axe, 스토리 axe, Lighthouse)로 볼 수 없는 것을 실제 기기와 화면 낭독기로 확인합니다. 하나라도 실패하면 GitHub 이슈로 남기고, 고친 뒤 v1.0.0 태그를 붙입니다.

## 준비

| 항목 | 내용 |
|---|---|
| 키오스크 기기 | iPad(최신 iPadOS, Safari, 손쉬운 사용 > 사용법 유도 접근으로 한 앱 고정) 1대, Android 태블릿(Chrome, 화면 고정 또는 키오스크 앱) 1대 |
| 직원 PC | Windows + Chrome(또는 Edge) + NVDA, macOS + Safari + VoiceOver 중 하나 이상 |
| 손님 휴대전화 | iPhone(Safari + VoiceOver), Android(Chrome + TalkBack) |
| 서버 | 배포한 백오피스·런처·홈페이지, 또는 같은 네트워크에서 `pnpm build && pnpm start`. 런처는 백오피스 **매장 관리 → 매장 메뉴 → 키오스크 토큰**에서 발급한 토큰으로 띄웁니다 |
| 데이터 | 시험용 매장 하나(테이블 등록), 예약 몇 건, 시험용 휴대전화 번호 |

기록: 기기·OS·브라우저·화면 낭독기 버전, 항목별 통과/실패, 실패한 화면 사진.

## 1. 키오스크 (매장 태블릿)

- [ ] 고정 모드에서 주소창·홈 제스처·알림 센터로 키오스크를 벗어날 수 없다
- [ ] 시작 화면의 큰 버튼을 손가락으로 쉽게 누를 수 있다(작은 기기 포함). "지금 바로 이용 가능 N종"이 1분 안에 바뀐다
- [ ] 두 손가락으로 확대할 수 있고, 한동안 만지지 않아 처음 화면으로 돌아가면 원래 크기로 돌아온다
- [ ] 게임 둘러보기: 인원·유형 필터, 긴 목록 스크롤이 오래된 태블릿에서도 끊기지 않는다
- [ ] 예약 확인: 숫자 패드로 뒷자리 4자리를 넣으면 오늘 예약이 나오고, 도착을 누르면 카운터 화면에 15초 안에 '도착'이 보인다
- [ ] 대기 등록: 이름·휴대전화·인원을 넣고 등록하면 번호표가 나오고 카운터 화면에 15초 안에 보인다. 잘못 넣으면 그 칸으로 초점이 가고 오류가 읽힌다
- [ ] 결과 화면(예약 확인·대기표·내 순서): 30초 뒤 경고 창이 뜨고, '계속 보기'를 누르면 연장되며, 그대로 두면 20초 뒤 처음 화면으로 간다
- [ ] 와이파이를 끄면 화면 위에 연결 끊김 안내가 나오고, 그사이 누른 대기 등록은 다시 연결되면 이어서 보내진다
- [ ] 끊긴 채 새로고침하면 브라우저 오류 대신 안내 화면이 나오고, 연결되면 처음 화면으로 돌아간다
- [ ] 화면 낭독기(VoiceOver·TalkBack): 화면마다 제목이 읽히고, 버튼 이름·숫자 패드·결과·시간 경고 창이 한국어로 빠짐없이 읽힌다

## 2. 백오피스 (직원)

- [ ] 마우스 없이 키보드만으로: 로그인 → 사이드바 → 예약 등록(테이블 선택 포함) → 확정·입장 → 현장 대기 호출·입장을 끝낼 수 있고, 초점 표시가 늘 보인다
- [ ] 대화상자는 열면 첫 칸으로 초점이 가고, Esc로 닫으면 연 버튼으로 돌아온다
- [ ] 화면 낭독기(NVDA·VoiceOver): 표의 머리글, 차트 대신 Tab 초점으로 나타나는 표, 새 대기·도착·온라인 예약 알림이 읽힌다
- [ ] 카운터 태블릿에서 손가락으로 예약·대기를 처리할 수 있고, 15초 자동 갱신 중에도 열어 둔 수정 창의 입력이 사라지지 않는다
- [ ] 두 직원이 같은 예약을 동시에 고치면 나중 저장이 막히고 안내가 나온다
- [ ] 브라우저 확대 200%에서 내용이 잘리지 않고, 넓은 표는 가로로 넘겨 볼 수 있다
- [ ] 매장 관리 → 테이블: 테이블을 더하고 끄면 예약 폼의 테이블 선택과 자동 배정에 바로 반영된다

## 3. 홈페이지 온라인 예약 (손님 휴대전화)

- [ ] 메뉴의 '온라인 예약'에서 매장·날짜·인원을 고르고 '빈 시간 보기'를 누르면 시각이 나온다(마감 시각은 '마감'으로 읽힌다)
- [ ] 시각·이름·휴대전화·동의를 넣고 예약하면 '예약했습니다' 화면으로 초점이 가고 매장·방문 시각·인원·테이블이 읽힌다
- [ ] 동의 없이 보내면 동의 칸으로 초점이 가고 오류가 읽힌다. 같은 번호로 그날 다시 예약하면 휴대전화 칸에 안내가 나온다
- [ ] 예약이 백오피스 예약 목록에 '온라인' 배지와 테이블로 보이고, 카운터 화면이 화면 낭독기로 알린다
- [ ] 예약한 날 매장 키오스크의 '예약 확인'에서 뒷자리로 찾아 도착을 알릴 수 있다
- [ ] 홈페이지에 예약 설정(`BACKOFFICE_URL`, `BOOKING_API_TOKEN`)이 없으면 예약 화면이 매장 전화번호를 안내한다

## 4. 운영

- [ ] Sentry DSN을 넣고 일부러 오류를 내면 이벤트가 들어오고, 이벤트에 손님 이름·전화번호·쿠키가 없다
- [ ] 보관 기간 정리(Vercel Cron 또는 `db:prune`)를 한 번 돌려 로그에 지운 수가 남는다
- [ ] `db:backup`으로 백업한 뒤 새 DB에 `db:restore`하고, 로그인·목록·예약이 그대로 보인다
